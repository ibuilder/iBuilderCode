# iBuilder Code Website

Welcome to the iBuilder Code website! This project serves as a documentation and demo site for various tools developed by Matt Emma. Below you will find information on how to set up the project, its features, and other relevant details.

## Project Structure

The project consists of the following files and directories:

```
ibuilder-code-website
├── index.html          # Main landing page
├── faq.html            # FAQ section
├── css
│   └── style.css       # Styles for the website
├── js
│   └── script.js       # JavaScript for interactive features
├── img
│   └── logo.svg        # Logo in SVG format
└── README.md           # Project documentation
```

## Features

- **Landing Page**: The main page includes a jumbotron header to capture user attention, links to GitHub repositories, and demonstrations for various tools.
- **Demonstrations**: Direct links to demos for tools such as:
  - [PrcoreAPI Invoice](https://github.com/ibuilder/ProcoreAPI-PHPInvoice) - [Demo](https://ibuildercode.com/invoice/)
  - [NYC-BrownstoneIFC](https://github.com/ibuilder/NYC-BrownstoneIFC)
  - [PMxl](https://github.com/ibuilder/PMxl)
  - [RExl](https://github.com/ibuilder/RExl)
- **FAQ Section**: A dedicated FAQ page that includes GitHub Gist snippets for additional resources.
- **Contact Form**: A contact form that sends inquiries to contact@ibuildercode.com.
- **Social Media Links**: Links to the developer's blog and social media profiles in the footer.
- **Theme Toggle**: Light and dark mode support with persistence via localStorage.

## Setup Instructions

1. Clone the repository:
   ```
   git clone https://github.com/ibuilder/ibuilder-code-website.git
   ```
2. Navigate to the project directory:
   ```
   cd ibuilder-code-website
   ```
3. Open `index.html` in your web browser to view the landing page.
